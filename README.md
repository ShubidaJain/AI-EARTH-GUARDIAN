# AI Earth Guardian

AI-powered environmental monitoring, prediction, and risk assessment platform.

## Project Components

- iOS application using SwiftUI
- Machine Learning models using Python
- FastAPI backend
- Environmental and geospatial data processing
- Environmental risk detection and prediction

## Modules

- Forest Fire Intelligence
- Deforestation Detection
- Air Pollution Prediction
- Flood Risk Prediction
- Wildlife Monitoring

## Technology Stack

### iOS

- Swift
- SwiftUI
- MapKit
- CoreLocation
- Swift Charts

### AI/ML

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- PyTorch

### Backend

- FastAPI
- PostgreSQL
- PostGIS
